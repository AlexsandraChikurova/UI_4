# Мопс & Мат

Учебный сайт бронирования йоги и отдыха с мопсами. HTML, CSS и JavaScript с ES-модулями. Сборка и установка зависимостей не нужны.

## Возможности

- Пять мопсов: выбор стрелками, клавиатурой или свайпом, мягкие движения фотографий.
- Две локации, расписание на три дня, восемь ковриков в каждом сеансе.
- Схема и список мест, фильтры зоны и цены, выбор одного или двух ковриков.
- Проверка заказа, демонстрационная оплата, билет с анимацией одобрения и печатью.
- Сохранение брони в браузере, просмотр и отмена встречи.
- Адаптивный интерфейс и возможность приостановить движения.

## Файлы

| Файл | Назначение |
| --- | --- |
| index.html | Главная страница |
| style.css | Оформление и адаптивность |
| app.js | Интерфейс и бронирование |
| model.js | Данные, расписание, тарифы и проверка брони |
| tickets.js | Разметка билета |
| motion.js | Анимация одобрения |
| idle-motion.js | Движения мопсов на первом экране |
| credits.html | Фотографии и сведения о материалах |
| assets/ | Пять фотографий мопсов и две фотографии локаций |
| .nojekyll | Публикация статических файлов без обработки шаблонов |
| preview.mjs | Локальный HTTP-сервер для разработки |
| tests/ | Проверки логики бронирования |
| package.json | Настройка модулей и команды проверки |

Все фотографии из assets используются сайтом. Файлы JavaScript связаны импортами: удалять отдельные модули нельзя.

## Локальный запуск

Из папки проекта:

```sh
node preview.mjs
```

Открыть http://127.0.0.1:8047/. Альтернатива: `python -m http.server 8000` из той же папки. Для ES-модулей нужен HTTP; открывать страницу двойным щелчком не следует.

## GitHub Pages

Загрузить содержимое этой папки в корень нового репозитория: index.html должен находиться сразу в корне, а не во вложенной папке. В Settings → Pages выбрать Deploy from a branch, ветку main, папку /(root), затем Save.

Для работы сайта достаточно index.html, style.css, всех пяти файлов .js, credits.html, assets/ и .nojekyll. README.md, .gitignore, package.json, preview.mjs и tests/ можно также загрузить: они документируют проект и помогают его проверять.

## Проверка

```sh
node tests/model.test.mjs
```

Проверяются календарные ID, тарифы, невалидный выбор, занятость разных сеансов, сохранение, отмена и повторная бронь.

## Ограничения и материалы

Это учебное демо: деньги не списываются, настоящая запись не создаётся, данные карты не собираются. Брони хранятся только в текущем браузере. Для общей записи с разных устройств потребуется сервер. Конкретная собака не закрепляется за участником.
